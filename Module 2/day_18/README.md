# Day 18: Arrays, Objects & Modern JS

## Module Breakdown
- `transactions.js`: Data module exporting array of TeleBirr transaction objects.
- `report.js`: Pure reporting module exporting functions for total calculations, receipt generation, and immutable updates.
- `app.js`: Main entry point importing business logic and rendering formatted reports to console.
- `money.js` & `exercises_app.js`: ES Module export and import demonstration.
