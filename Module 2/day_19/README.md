# Day 19: DOM Manipulation & Events

This directory contains the Day 19 coursework, split into daily warm-up exercises and the Week-2 project deliverable.

## Directory Structure
- **`exercises/`**: Solutions to the 5 warm-up exercises covering element selection, `classList.toggle`, dynamic list generation, event bubbling, event delegation, and form handling with `preventDefault()`.
- **`addis-market/`**: The Week-2 interactive shopping list application built using pure DOM manipulation and event delegation.

## How to Run
Open `index.html` in either subfolder directly in any browser.
